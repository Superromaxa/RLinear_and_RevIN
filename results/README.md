# Контролируемые проверки RLinear на ETTh1

Протокол и ставки зафиксированы в коммите `dec92df` до запусков. На локальном CPU обучили по три модели в каждой из трёх конфигураций. Для всех использовали H = 96, сиды 1024, 1025 и 1026, одинаковые точки прогнозирования и выбор чекпоинта по validation MSE. Сводка ниже показывает среднее ± выборочное стандартное отклонение по сидам. [Метрики каждого запуска и границы окон](rlinear-etth1.json)

| История | RevIN | MSE на полном test | MAE на полном test |
|---:|:---:|---:|---:|
| 336 | Вкл. | 0,38965 ± 0,00641 | 0,40827 ± 0,00400 |
| 336 | Выкл. | 0,38678 ± 0,00595 | 0,41191 ± 0,00695 |
| 96 | Вкл. | 0,38915 ± 0,00052 | 0,39753 ± 0,00033 |

## Сверка со ставками

- **RevIN.** При L = 336 на исходном test включение RevIN увеличило средний MSE на 0,74%. При этом MAE снизилась. Общий критерий проекта оценивается по пяти архитектурам, поэтому для него этих данных пока недостаточно.
- **Drop-last.** Удаление последних 97 из 2 785 окон снизило MSE на всех трёх сидах. Медианное абсолютное изменение составило **1,24%**, что укладывается в ставку «менее 3%».
- **Длина истории.** При включённой RevIN переход с 96 на 336 увеличил средний MSE на **0,13%**. Ставка на снижение минимум на 2% не подтвердилась.
- **Сдвиг уровня.** При добавлении +2 к истории и целям MSE с RevIN изменился менее чем на 0,001%. Без RevIN он вырос на **36,57%**. Оба результата укладываются в ставки для расширения.

Здесь применены постоянный LR, общие окна и полный test, поэтому числа этого эксперимента относятся к проверкам протокола.
